# Onboard

Modified from Impeccable 4.1.1 at `56f44523f76efdcec813e67b38ee550e49b16f48` under Apache-2.0.

## Scope

Reduce time to first value for new, returning, or newly authorized users.

## Diagnose

Identify the user's starting knowledge, motivation, first valuable outcome, current drop-off, required setup, and the minimum concepts needed to reach that outcome.

## Evidence

Trace welcome, setup, first action, first success, empty states, skip, resume, dismissal, replay, error, and accessibility paths with realistic content.

## Guardrails

Do not teach every feature, block experienced users, patronize, fabricate value claims, repeat dismissed guidance, or build a tutorial disconnected from the real product.

## Handoff

Prefer working examples, progressive disclosure, and contextual help. Delegate behavioral implementation and persistence to `implement` or `developing-changes` when available.

## Completion

The user can reach the defined first value quickly, skip or recover safely, and understand the next useful action across representative states.
