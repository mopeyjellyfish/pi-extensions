# Harden

Modified from Impeccable 4.1.1 at `56f44523f76efdcec813e67b38ee550e49b16f48` under Apache-2.0.

## Scope

Make an implemented interface resilient across real data, failure, permission, input, locale, and device conditions.

## Diagnose

Inventory loading, empty, error, offline, timeout, partial success, disabled, permission, destructive, concurrency, long-content, localization, zoom, focus, and responsive paths.

## Evidence

Exercise applicable states with reproducible inputs; record recovery behavior, preserved user work, announced status, runtime errors, overflow, and unavailable environments.

## Guardrails

Do not invent backend guarantees, swallow errors, disable safety checks, truncate meaningful content, or use cosmetic fallbacks that misrepresent state.

## Handoff

Prioritize blocked tasks and data-loss risk before finish defects. Delegate behavioral implementation to `implement` or `developing-changes` when available.

## Completion

Applicable edge cases have observable recovery and accessible state communication; unsupported proof remains explicit.
