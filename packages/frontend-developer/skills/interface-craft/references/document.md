# Document

Modified from Impeccable 4.1.1 at `56f44523f76efdcec813e67b38ee550e49b16f48` under Apache-2.0.

## Scope

Create, seed, merge, or refresh durable design documentation through `design-documentation`.

## Diagnose

Choose scan, seed, or merge/refresh mode from implementation evidence, accepted direction, and the existing document. Identify settled tokens, provisional decisions, drift, and unknown content.

## Evidence

Trace each proposed rule to repeated code, representative rendered behavior, or an explicit human design decision.

## Guardrails

Repository instructions and verified behavior outrank the document. Never invent values, silently overwrite, discard unknown sections, or create sidecar state.

## Handoff

Delegate proposal and approval ownership to `design-documentation`; delegate any accepted implementation change to `implement` or `developing-changes` when available.

## Completion

The complete portable proposal is shown, conflicts and omissions are explicit, and no file is created or materially rewritten without human approval.
