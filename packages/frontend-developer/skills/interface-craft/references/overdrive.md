# Overdrive

Modified from Impeccable 4.1.1 at `56f44523f76efdcec813e67b38ee550e49b16f48` under Apache-2.0.

## Scope

Push an explicitly accepted expressive direction beyond conventional treatment while preserving a production interface.

## Diagnose

Name the creative thesis, focal workflow, technical opportunity, incumbent signature, acceptable performance budget, and the exact convention being exceeded for product-specific reasons.

## Evidence

Prototype and compare the ambitious treatment across representative states, viewports, input modes, reduced motion, contrast, loading, and lower-capability devices.

## Guardrails

Do not use spectacle to conceal weak hierarchy, ship illegible generated text, block the task, create inaccessible custom controls, or accept unbounded paint, memory, network, or motion cost.

## Handoff

Isolate enhancement from core behavior and define a robust fallback. Delegate behavioral implementation to `implement` or `developing-changes` when available.

## Completion

The result is technically ambitious and product-specific, yet the focal workflow, accessibility, responsive behavior, fallback, and measured performance remain sound.
