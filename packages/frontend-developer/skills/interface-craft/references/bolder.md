# Bolder

Modified from Impeccable 4.1.1 at `56f44523f76efdcec813e67b38ee550e49b16f48` under Apache-2.0.

## Scope

Increase deliberate expression in a safe or bland interface without obscuring the focal task.

## Diagnose

Identify where default typography, weak proportion, timid contrast, generic composition, or an absent product signature makes the interface interchangeable.

## Evidence

Compare the incumbent and stronger direction at representative states and sizes; show how the focal workflow, signature, hierarchy, and accessibility change.

## Guardrails

Bold does not mean more decoration, colors, gradients, motion, or scale everywhere. Preserve legibility, semantic color, task speed, content truth, and the accepted visual world unless redesign is explicit.

## Handoff

Name the few systemic levers that create the stronger direction and delegate behavioral implementation to `implement` or `developing-changes` when available.

## Completion

The result is recognizably more product-specific and expressive while the task, states, responsive behavior, and accessibility remain clear.
