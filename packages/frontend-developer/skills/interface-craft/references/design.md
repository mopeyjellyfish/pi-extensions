# Design

Modified from Impeccable 4.1.1 at `56f44523f76efdcec813e67b38ee550e49b16f48` under Apache-2.0.

## Scope

Establish a deliberate interface direction for a material web surface.

## Evidence

Record person, task, current authority, desired feel, focal workflow, states, responsive and accessibility constraints, and visual choices.

## Handoff

Delegate behavioral implementation to `implement` or `developing-changes` when available; otherwise use the direct-parent fallback.

## Completion

The direction is explicit, evidence-backed, and any missing proof is reported.
